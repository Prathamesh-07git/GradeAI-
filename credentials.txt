=== How to Run GradeAI ===

1. RUN THE BACKEND (from the main `auto-grading-nlp` folder):
Open a terminal and run the following command to start the FastAPI server:
.\venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload

2. RUN THE FRONTEND (from the `frontend` folder):
Open a second terminal, change into the frontend directory, and start the React server:
cd frontend
npm run dev
